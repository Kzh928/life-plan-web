# v4=2：機能の配置と計算

v4=1で確認なく簡略化してしまった機能を戻す更新．既存v4の予定・実績・当初予算は保持し，v1〜v3には変更しません．以後の機能削除は先に利用者へ確認します．

| 機能 | v4での場所・関係 |
| --- | --- |
| 月の実績・コメント・確定・残高の控え | 記録する．どの案でも共通 |
| 生活費等の推移・平均 | 記録する内の実績集計 |
| 本人・パートナーの働き方パターン | 予定を決める → 収入・働き方 |
| 年間手取り／年収の下限・上限×手取り率 | 各収入パターンの基本設定・年度別一覧．同一収入の代替額として使用 |
| 年度別一括入力・収入JSON | 各収入パターン．従来の年度別収入JSONも明示操作で読込可能 |
| 退職金 | 各収入パターンの受取予定．年度と月を指定し，その月の特別収入へ1回反映 |
| 生活費パターン | 費目ごとの月額＋年額，物価，複製，使用開始月を設定 |
| 住居費パターン | 月額＋年額，複製，使用開始月を設定 |
| 既存の毎月項目 | 引き続き編集可能．同じ識別子のままパターン化できるため，実績との対応を保持 |
| ライフイベント | 1回・繰り返し・月移動・複製．記録済み実績は旧月に残す |
| 用途別積立 | 用途ごとに開始残高を割当．毎月の任意積立と，購入費用÷周期の自動積立に対応 |
| 積立から購入 | 指定した用途だけから充当し，不足分は現金．生活費＋積立と現金流出を区別して表示 |
| 教育費マスタ | 子ども・教育 → マスタ確認・編集．元データはv1と同じ．案ごとの上書き・JSONを保存 |
| 教育費の反映 | 子どもの設定で反映年度・金額をプレビュー．年度別にマスタの内訳，出生前，0円の理由を表示 |
| 教育の年度別手入力・進路・奨学金 | 子どもの設定・年度別一覧．明示的な0円も反映 |
| NISA・投資 | 元本／利益，購入上限，取得元本枠，売却元本枠の復元時期，自動取り崩し条件を設定 |
| 当初予算 | 12か月一括・手入力．その後の予定増額では変更しない |
| 別案比較 | 予定と条件だけを分岐し，実績と開始残高を共有 |
| 空から再入力 | 右上メニューから新しい空ノートを作成．以前のノートを保持 |
| 保存・端末移動 | 専用v4保存と全データJSON．旧アプリから自動取得しない |

## 入力操作

タブは上部．入力・選択欄の文字は16px以上とし，iPhoneの入力フォーカス時の自動拡大を避ける．手動ピンチズームは制限しない．金額は桁区切りと円表示．数値欄はフォーカスとタップで全選択．実績金額の確定時には入力DOMを再生成せず，合計のみ更新する．

## 積立の会計

月々の積立は現金を減らし，別枠貯金を増やす．家計から自由に使える額は減るが，総資産は変わらない．購入時に支出を計上し，同じ用途の別枠から現金へ充当する．不足しても別用途の残高を使わない．したがって，積立と購入の両方を総資産の減少として二重計上しない．

## 投資の条件

上限は利用者が入力する試算用の値．未入力は制限しない．上限は未入力の購入予定に適用し，入力済みの購入実績を書き換えない．元本と利益の比率で売却し，元本の枠を指定した時期に復元．確定済み月には自動売却を追加しない．上限の年度は4月〜翌3月，税・手数料・制度の適用判定は自動計算しない．

## 検証

計算・フォーム操作・保存テストと，実際の教育費マスタ・元本比率・用途別資金のテストを含む．旧v4=1の保存データを設定変更なしで計算したときの主要金額の一致も確認．公開版のChromiumで金額の桁区切り・全選択・置き換え，16pxの入力欄，上部タブ，次の欄のフォーカス保持，マスタの反映プレビュー，収入パターンの入口も確認．iPhone実機の入力挙動は未検証．
