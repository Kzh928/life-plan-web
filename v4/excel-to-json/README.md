# Excelから収入JSONへ

既存の `.xlsx` に保存された手取り金額を読み取り、お金のノート v4=13 以降に取り込む収入案JSONを作成します。Excel本体・数式・金額を送信する処理はありません。数式の実行や外部ライブラリの取得も行いません。

## 使い方

1. Excelで再計算して保存した `.xlsx` を選ぶ。
2. 対象者、働き方、年月・年度と金額の列、行の範囲を確認する。候補が見つからない表は手動で指定する。
3. 年間手取りだけの表は「年間手取り」を選ぶ。年間額に含まれる賞与を推測して分割しない。
4. 月給と賞与が分かれている表は「月給と賞与の手取り」を選び、賞与列と支給月を指定する。
5. 金額と働き方の切替月を確認してJSONを保存する。
6. 家計簿の「収入」→「年度別収入をまとめて読み込む」で選ぶ。新しい収入案を追加し、現在の全体プランに適用するかを選ぶ。

金額は手取りの列を指定します。会社独自の計算はExcelに残してください。旧 `.xls`、パスワード付きファイル、25MBを超えるファイルは対象外です。保存済みの計算結果がないセルはエラーにします。空欄と0円を区別します。

## 月給・賞与の扱い

月給は変更月から次の変更まで継続し、年間手取りの設定より優先します。同額が続く行は変更履歴にまとめます。賞与は支給月だけに加算し、翌年には自動で繰り返しません。月ごとの表では賞与額がある行の年月と指定した支給月が一致する必要があります。年間手取り方式は4月始まりの年度です。

従来の特別収入と賞与の支給月が重なる場合、取り込み確認画面で「同じ賞与」か「別の収入」かを選択します。同じ賞与なら従来の実績IDに対応付け、その月の予定は1回だけ計上します。従来のイベント案と共通実績は残し、JSONにない支給月は従来の予定を使います。

予定と実績は別データです。予定を更新しても実績は書き換えません。見込みには入力済み実績と未入力の予定を使います。確定済みの月は従来どおり入力済み実績だけを使います。

## JSON（架空の例）

```json
{
  "format": "jp.finance.income.sources",
  "version": 2,
  "sources": [{
    "owner": "self",
    "name": "Excelからの収入案",
    "start": "2026-04",
    "end": "",
    "patterns": [{
      "id": "style1",
      "name": "正社員",
      "years": {},
      "salaryChanges": [
        {"from": "2026-04", "netMonthly": 250000},
        {"from": "2027-04", "netMonthly": 260000}
      ],
      "bonuses": [{"month": "2026-06", "net": 400000}]
    }],
    "stages": [{"month": "2026-04", "patternId": "style1"}]
  }]
}
```

`owner` は本人が `self`、パートナーが `partner`。年間手取りの場合は `years` を `{"2026":{"netAnnual":3600000}}` の形にし、月給と賞与の配列を省略します。年間額だけの方式では記載のない年度は0円です。従来のバージョン1も読み込めます。

列の設定を保存した場合だけ、対象者・働き方・シート・行・列・切替月を端末のローカルストレージに保存します。Excelと読み取った金額は保存しません。書き出したJSONには金額が含まれるので、個人用として保管してください。
