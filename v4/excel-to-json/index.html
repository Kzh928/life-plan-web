EXCEL → JSON

計算はExcelで．
金額だけ，家計簿へ．

保存済みの手取りを取り出して，収入案として読み込めるファイルにします．Excelや金額をサーバーへ送信しません．

  1. Excelを選ぶ
  2. 列を合わせる
  3. 確認して保存

1Excelを選ぶ

Excelで再計算して保存したファイルを使ってください．数式は読み出さず，保存された計算結果を使います．パスワード付き・旧.xls形式は対象外です．

ファイルを選ぶと，シートと読み取り候補が表示されます．

シートの中身

先頭60行・24列までを表示します．式の内容は表示しません．変換では指定した行をすべて読み取ります．

2取り出す列を合わせる

1つの設定が1つの働き方です．本人・パートナーは別の収入案になります．候補の対象者・列・開始月を確認してください．

保存するのは対象者・働き方・シート・行・列・切替月の設定です．Excel・金額・数式は保存しません．

3金額を確認して保存

お金のノート v4=13以降の「収入」→「年度別収入をまとめて読み込む」で選択してください．既存の収入案と実績は残ります．JSONには金額が含まれるので，ご自身で保管してください．

通信・解析サービス・外部ライブラリの読み込みを使わず，この画面の中で処理します．手取り計算や会社独自の賞与計算はExcel側で行ってください．
