# お金のノート v4=1

v1・v2・v3とは別のデータ，別の画面で，空から始めるアプリです．旧バージョンを読み込む処理，旧画面の埋め込み，自動データ移行はありません．

## 画面

- 記録する：月の実績，コメント，残高の控え，確定済み月の推移・平均．実績はノート内の全案で共通．
- 予定を決める：毎月の項目，変更月，年度別金額，イベント，子ども・教育，当初予算，分岐．
- 先を見る：未入力は案ごとの予定，入力済みは共通実績を使う月・年の資産推移と比較．使った項目の内訳を表示．
- 右上メニュー：新しい空ノート，ノート切り替え，開始残高，JSON書き出し・復元，変更履歴．

## 一つの予定データ

月額と年度別入力は同じ項目の別の設定であり，加算しません．年度別金額を優先し，それがなければ月額変更履歴，次に基本額を使用します．最後に「この月だけ」の上書きを適用します．イベントは指定年月へ直接計上します．教育費マスタは明示的に有効にした場合だけ使います．

入力途中は項目単位で実績を置き換え，未入力は予定を使用．確定済み月は未入力を0円とします．イベントを移動・削除しても入力済み実績は元の月へ残します．当初予算はスナップショットで，予定変更から独立．部分的な当初予算の年度比較は，設定した項目・月の共通範囲で集計します．

開始残高はノート内で共通．投資・別枠貯金への移動は総資産を変えず，収支と運用益だけが総資産を変えます．別枠からの支出では，利用できる別枠残高まで現金へ充当．現金不足で投資を自動売却しません．制度上限，税，手数料の自動判定は行いません．想定利回り・物価率が未入力なら0％で計算します．開始残高の未入力も画面で明示します．

## 保存

専用IndexedDB `finance-v4-local`，専用キー `finance-v4-state`．DB利用不可時は同じ専用接頭辞のlocalStorageへ保存．旧版の値を読み取る呼び出しはありません．JSONは全ノートを含む `jp.finance.v4` version 1．復元前に構造・識別子・参照を検証します．旧版のJSONは自動解釈しません．ブラウザ間の自動同期はありません．
