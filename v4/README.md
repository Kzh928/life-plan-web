## v4=10：所属が分かる階層と案の適用

収入案→本人／パートナーの収入→働き方→金額と切替時期を，段差と左罫線のある入れ子で表示．使う期間は各働き方の金額と同じ場所に表示し，そこから追加・変更できる．複数の加算する収入枠が残っている場合は枠番号と合算の説明を付け，削除もその枠から操作可能にした．

開始年度・終了年度・基準の年間手取りと，毎年の昇給率／昇給額／同額を指定して年度別手取りを設定できる．昇給率は前年額への複利，昇給額は年ごとの固定加算，円単位に四捨五入．全対象年度を検証してから一括反映し，対象外の年度・額面試算・退職金・切替設定は保持する．

生活費では表示月に使う費用パターンの余分な見出しを省き，案の直下に生活費・固定費・定期支出を並べる．別の時期のパターンは管理欄から編集可能．住居費は見出し→案→各住まいの金額・使用時期へ整理．編集中の案と全体プランに適用中の案を並べ，適用ボタンで現在の全体プランの採用先を更新する．編集・試算する案の選択だけでは採用先は変更しない．適用後の月予定は選んだ案から計算し，共通実績のID・金額は変更しない．

## v4=4：元データと全体プランの組み合わせ

収入・住居費・生活費の案は `notebook.categoryCatalog` で独立して保持．全体プランは `categorySelections` に各種類の採用IDを保存する．同名でも収入と住居費の案は別のもの．全体プランの分岐は採用IDを引き継ぎ，元データを複製しない．共通実績はノート単位．

「予定を決める」の収入・住居費・生活費は元データの編集．編集対象や新規コピーの選択では，全体プランの採用先を変更しない．「先を見る」で採用する組み合わせを選び，全体プランごとに自動保存する．元データの編集はその案を採用している全プランへ反映し，編集画面に採用中のプラン名を表示．異なる条件はコピーして試す．月だけの上書きも元データの案ごとに保持．

v4=1〜3は数値を保持して変換．同一内容の元データは共通化し，異なる内容は別の案として保持．退職金・年度別金額・切替時期・働き方・項目IDを維持．全元データと全体プランの採用関係はv4 JSONに含まれる．旧版v1・v2・v3や添付Excelは変更しない．

v1・v2・v3とは別のデータ，別の画面で，空から始めるアプリです．旧バージョンを読み込む処理，旧画面の埋め込み，自動データ移行はありません．

## 一つの予定データ

月額と年度別入力は同じ項目の別の設定であり，加算しません．年度別金額を優先し，それがなければ月額変更履歴，次に基本額を使用します．最後に「この月だけ」の上書きを適用します．イベントは指定年月へ直接計上します．教育費マスタは明示的に有効にした場合だけ使います．

入力途中は項目単位で実績を置き換え，未入力は予定を使用．確定済み月は未入力を0円とします．イベントを移動・削除しても入力済み実績は元の月へ残します．当初予算はスナップショットで，予定変更から独立．部分的な当初予算の年度比較は，設定した項目・月の共通範囲で集計します．

開始残高はノート内で共通．投資・別枠貯金への移動は総資産を変えず，収支と運用益だけが総資産を変えます．別枠からの支出では，利用できる別枠残高まで現金へ充当．自動取り崩しは指定した場合だけ行います．制度上限，税，手数料の自動判定は行いません．想定利回り・物価率が未入力なら0％で計算します．開始残高の未入力も画面で明示します．
