# ポケポケノート・GitHub Pages版

公開URL：https://kzh928.github.io/life-plan-web/pokepoke/

## 最初の移行
1. いつも使っている端末・ブラウザで元サイト https://twelve-count-memo.etsu-211fe.chatgpt.site を開く．
2. 一番上の「バックアップ・移行」→「全データを書き出す（JSON）」を押す．ファイルは端末の「ダウンロード」または「ファイル」に保存する．
3. 新URLを同じブラウザで開く．「バックアップ・移行」→「バックアップを読み込む」でJSONを選ぶ．
4. 検証後の件数を確認し，「現在のデータをバックアップして復元する」を押す．現在の内容のJSONダウンロードと，端末内の直前バックアップも作る．自動ダウンロードが制限される場合は，先に「全データを書き出す」を押して保管する．
5. アカウント名・メール・コード・各項目・ポイント・カード枚数・完了状態・好きな順・金フレームを確認し，再読み込みして内容が残ることを確認する．確認が済むまで元サイトとJSONを残す．

元サイトのデータは別ドメインのため，新サイトから自動で読み取れない．元サイトへのログインが必要なのは最初の書き出しだけ．元サイト側のブラウザ表示設定や未保存入力も，その端末で書き出した場合に含む．別端末にしかない未保存入力は，その端末でも書き出す必要がある．

## 保存とバックアップ
IndexedDBに全データ，localStorageに表示設定と入力途中の値を保存する．入力内容をサーバーへ送る処理はない．同じURLでも別の端末・ブラウザには別のデータが保存される．同じ端末・同じブラウザプロファイルを使う人には見えるため，端末の共有には注意する．ブラウザデータ消去・シークレットモードの終了では失われることがある．定期的にJSONを端末の外にも保存する．

読み込みはJSONの型・上限・重複ID・完了条件を検証してから行う．不正なファイルは読み込まない．書き換えはIndexedDBの単一トランザクションで行う．「読み込み前のデータを書き出す」で直前の状態を回収できる．このボタンの内容は次回の正常な読み込みで置き換わる．全体を置き換える復元であり，複数バックアップの自動合成は行わない．

全アカウント・12カウント・おすそわけ・分類・メモ・数値・自由項目・並び順・設定・完了状態・関連を含む．以前の「pokepoke-notebook」「pokepoke-collection」JSONも対応．写真・PDFの登録機能は元実装にもない．文章内の外部URLは引き継ぐが，リンク先や認証の継続に依存する．添付ファイル付きの未知の形式は黙って捨てずに拒否する．

## 独立運用
ChatGPTログイン・Sites API・AI API・共通DB・有料サービス・CDNを使わない．既存画面のAPI操作を端末内トランザクションへ置き換えている．画面間の移動は同じディレクトリのクエリ形式なので，GitHub Pagesのサブディレクトリで動く．Service Workerはこのディレクトリだけをキャッシュする．初回は通信が必要．オフラインキャッシュは補助であり，データのバックアップではない．自動収集やAI機能は元実装にない．パック名は内蔵一覧で，将来の新パック追加はコード更新が必要．

GitHub Pagesの同一オリジン内ではブラウザ保存領域を共有する．この版は専用DB名を使うが，他の公開アプリも信頼できるコードだけを同じオリジンに置くこと．Pagesの停止に備える場合はプログラム一式をGitHubからダウンロードして別の静的HTTPSホストへ置き，JSONを復元できる．ホストを変更するとブラウザデータは自動では移らない．

## ソースとビルド
公開しているのはプログラムと公開用スタイルのみ．バックアップ・メール・認証情報・元サイトのDB・サーバーコードは含めない．`source/`が静的版のソース．Node.js 22.13以上で，source内で `npm install`，`npm run build` を実行すると `portable-build/index.html` と `sw.js` ができる．これを公開フォルダに置く．ビルド済みHTMLにはJS/CSSを内蔵しており，閲覧時の外部依存はない．更新時はindex.htmlとsw.jsを同時に配布する．
