# ひとメモ v22 引っ越し手順

このフォルダーは静的なHTML・JavaScriptだけで動きます．サーバー，PHP，ChatGPTログイン，AI APIは不要です．フォルダーごと通常の静的ホスティングで公開できます．個人データをリポジトリへ置かないでください．

## 元サイトから

1. いつも入力しているスマホ・ブラウザで元サイトを開きます．
2. 設定 →「全ノートの引っ越し」→「全ノートを書き出す」を押し，JSONをファイルアプリへ保存します．
3. 新しいサイトを同じブラウザで開き，設定 →「全ノートを読み込む」でJSONを選びます．
4. 表示された件数を確認します．現在の全ノートを書き出し，保存完了を確認してから復元を押します．
5. 人物，情報，所属，関係，写真，並び順，相関図の配置を確認します．推しメモにも切り替え，再読み込みして保存状態を確認してください．

旧バージョンのノート別JSONも従来の「バックアップから復元」で読み込めます．旧暗号化バックアップは当時のパスワードが必要です．全ノートJSONに含まれる旧暗号化データは移行後の初回解除が必要です．未整理の下書きは事前に整理してください．

写真は登録時に端末内で縮小されたJPEG本体を含みます（撮影時の原寸画像ではありません）．本アプリにはPDF添付機能はありません．URLとして記録した動画・プロフィールなどは外部サイトの継続に依存します．

元サイトと新サイトの保存場所は別です．自動同期しません．保存先は現在使う端末・ブラウザで，ブラウザデータ削除で消えます．バックアップは暗号化されていない個人情報ファイルです．公開リポジトリへアップロードしないでください．元サイトと旧データは，移行を確認するまで残してください．

## GitHub Pages

公開先リポジトリの `hito-memo/` に本フォルダーのファイルを配置します．既存のPages公開ブランチから静的ファイルを配信します．アプリは相対パスで読み込むためサブフォルダーでも動作します．公開対象はアプリコード・公開されている推しの初期見本だけです．入力内容は端末内に保存され，他の訪問者とは共有されません．
