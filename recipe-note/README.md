# ごはんの手帖（独立版）

公開URL: https://kzh928.github.io/life-plan-web/recipe-note/

静的HTML 1ファイル．外部ライブラリ・ChatGPT認証・AI API・データ保存サーバーは使いません．個人データは各ブラウザのlocalStorageに保存．公開コードに個人のレシピ・画像は含みません．

## 元サイトからの移行
1. 以前使っていた端末・同じブラウザで https://gohan-recipe-note.etsu-211fe.chatgpt.site を開く．
2. 保存・取込 → バックアップを保存．JSONを端末のファイルへ保存する．
3. 新URLを開き，保存・取込 → 読み込み方法「完全復元」→ JSONを選択 → 確認する．
4. 件数・並び順・写真・わが家用・分量の分岐・記録を確認し，再読み込みして残ることを確認する．
5. 元サイトとJSONは移行確認が終わるまで残す．

旧形式も読み込めます．旧アプリでURL登録した写真がある場合は，旧サイトで写真を端末から登録し直して保存してから移行してください．このアプリで選択した写真は通常data URLで格納されています．独立版の完全バックアップは外部写真URLを実体化し，取得できなければ書き出しを中止します．URLだけで移行完了とはしません．

## バックアップ・復元
保存・取込 → 現在の全データを保存．一般用・わが家用・写真・工程写真・材料・機材・メモ・お気に入り・分岐のID・記録・順序・表示設定をJSONへ保存します．他人へ渡すときはレシピ単位の共有を使用してください．
読み込みは検証後に確認します．完全復元は同じIDを保持して置換．追加モードは関連IDを一緒に置き換えてコピーを追加します．保存は単一のlocalStorage書込で行い，容量不足や検証失敗では旧データを保持します．上書き前に必ず現在のバックアップを保存してください．

## 制約
- 保存済みPDFの管理機能は元アプリにありません．そのためPDF/ZIP移行の対象はありません．印刷からPDFを作る機能は引き続き利用できます．
- Web/X検索は外部検索を開く機能で，自動収集やAI自動取得ではありません．検索サービス・出典URLの継続に依存します．調べたレシピはJSONまたは手入力で追加できます．
- localStorageの容量はブラウザに依存（通常数MB）．写真が多い場合は保存を拒否し，旧データは残します．端末のデータ消去やプライベートモードにも注意してください．
- URL（オリジン）が変わると自動同期・自動移動しません．同じgithub.ioドメインに公開された他のアプリとオリジンを共有します．個人データをより分離したい場合は別ドメインを使用してください．
- index.htmlを保存して他の静的ホストへ配置できます．file://起動の保存動作はブラウザ依存です．HTTPSの静的ホストを推奨．

## 検証
空の保存領域への写真・順序・分岐・記録の復元，保存領域再読込，不正入力時の旧データ保持，コピー追加時の関連ID再割当，公開ファイルに個人の埋込データがないことを自動検証しました．ユーザーの端末内実データはサーバーから取得できないため，最終確認は上記手順で行ってください．
